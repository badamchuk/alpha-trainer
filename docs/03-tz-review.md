# Незалежна рецензія ТЗ і рішення за нею

_2026-09-17. Рецензію робив окремий агент, який читав ТЗ і код з нуля. Нижче — зауваження
(стисло), рішення і куди воно потрапило в ТЗ v2._

**Вердикт рецензента:** ТЗ правильно вгадує предмет (ідентичність вправи — корінь проблем), але
до реалізації не готове: три вимоги суперечать одна одній, тренерська модель ламається на
половині реальних вправ, обсяг завищено приблизно вдвічі.

## Критичні

| # | Зауваження | Рішення | Де в ТЗ v2 |
|---|---|---|---|

## Дрібні (усі прийнято)

Анімація 0.6–0.8 с замість 1.2; WebP на iOS — застереження в документації; `getItemLayout`/
`windowSize` для списку; нечіткий пошук лише коли точний дав 0; ліниві індекси; при імпорті
бекапу відсутні ключі очищаються; кнопка «Відео» офлайн неактивна; прибрані невживані поля
(`mechanics`, `unilateral`, `defaultSets`); одна мапа `Muscle → MuscleGroup` як джерело для решти;
`metrics: Metric[]` замість одного значення; кардіо сортується за спорідненістю модальності, а не
за Жаккаром; порожній стан для «Нещодавні».

## Чого бракувало (додано)

Семантичне ревʼю розмітки топ-40 вправ очима **до** злиття; незмінність `id` і тест на «сирітські»
зв'язки; правило рахунку метокону; поле `metKind`; поле `intent`; дисклеймер про біль; журнал і
скасування прив'язок; AI-тренер — явно поза межами ітерації; детальна міграція обладнання (у що
розгортається «Тренажерний зал», `band` у пресеті кросфіт-залу); порожні стани й доля чернетки
конструктора; метрики звіту «до/після» з порогом «розходження >20% по калоріях пояснюється».

## Скорочення обсягу (прийнято)

| Було | Стало |
|---|---|
| 7 форматів × 5 тривалостей × 3 фокуси = 105 комбінацій | 2 формати (Кросфіт, Фулбоді) × 3 тривалості (30/45/60) |
| 5 рівнів складності | 3 рівні + явні зв'язки `easierThan` |
| ≥200 вправ | ~150, але обов'язково всі історичні назви + кросфіт-набір |
| Блок «Складніше» в панелі заміни | Прогресії лишаються тільки в картці вправи |
| Список бібліотеки в промпт AI-плану | Прибрано: план і так проганяється через розпізнавання |
| Гілка «новачок» у конструкторі | Прибрано (користувач один, рівень intermediate) |
| `contextRules` | Прибрано |

## Відхилено / змінено проти рецензії

- **«Прибрати `secondaryPattern`»** — залишено: без нього трастер (присід + жим над головою) не має
  коректних кандидатів на заміну. Але тепер поле **використовується** правилом F4.3 і без нього
  вправа не пройде тест цілісності, якщо в неї складений рух.
- **«Прибрати `defaultReps`/`defaultSeconds`»** — залишено `defaultReps` і `defaultSeconds`: з них
  конструктор бере приписи для вправ, де схема залежить від вправи (планка в секундах, бурпі в
  повторах). Використання зафіксовано у F5.4.
